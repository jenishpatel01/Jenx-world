# JENX World

Portfolio of Jenish Patel — UI/UX designer & web app developer.

Single static page (`index.html`), no build step. Deploy on Vercel: import this repo, framework preset "Other", no build command.

Optional: add `Resume.pdf` next to `index.html` and a "Download Résumé" button appears automatically.

Contact-form messages are saved to the Supabase table `portfolio_messages` (project "jnx") and emailed via FormSubmit.
